# 作物倒计时管理系统 需求规格说明书（最终版）

## 1. 概述
一个基于浏览器的单页面应用，用于管理作物成熟与浇水倒计时。数据持久化于 `localStorage`，支持增删改查、浇水加速、排序、导入导出，并具备商业级视觉渲染和移动端适配。

## 2. 数据模型
每行数据包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | number | 唯一标识，自增id |
| `user` | string | 用户名称，可编辑，允许为空 |
| `cropType` | enum | `'16h'` 或 `'32h'` |
| `matureCountdown` | number | 成熟倒计时，剩余秒数（不允许负数，归零即为"已成熟"） |
| `waterCountdown` | number | 浇水湿润倒计时，剩余秒数（不允许负数） |
| `createOrder` | number | 递增序号，用于默认排序（按行添加先后） |
| `createdAt` | number | 创建时间戳（毫秒），用于恢复数据时的稳定性 |

### 计算属性（运行时动态计算）
- **水分干枯时间** = `当前时间 + waterCountdown`，格式 `MM-DD HH:mm`
- **作物总成熟时长**：16h 作物 = `57600s` (16×3600)，32h 作物 = `115200s` (32×3600)
- **最大湿润时间**：16h 作物 = `19200s` (5h20m)，32h 作物 = `38400s` (10h40m)
- **浇水可用阈值**：16h 作物剩余湿润时间 < 5h (`18000s`，不含等于)，32h 作物 < 10h (`36000s`，不含等于)
- **浇水减少时间** = `(最大湿润时间 - 浇水前剩余湿润时间) / 4`，取整
- **浇水成熟剩余时间**：
    - 若 `浇水减少时间 >= 成熟倒计时` → 显示"浇水立即成熟"
    - 否则若 `浇水湿润倒计时 > ((成熟倒计时 - 浇水减少时间) / 5 × 4)` → 显示"约x分钟后成熟"（x = `((成熟倒计时 - 浇水减少时间) / 5 × 4)` 换算为分钟，≥60分钟时显示"约x小时x分钟后成熟"）
    - 否则 → 显示"-"
- **跨日标签**：如果成熟倒计时或浇水湿润倒计时跨越自然日，在对应时间列后方显示"跨"标签

### 约束
- 成熟后（`matureCountdown <= 0`）：不允许浇水，允许修改、删除、一键播种
- 浇水湿润倒计时归零（`waterCountdown <= 0`）：仅视觉提示"水分干枯"，无其他惩罚，允许浇水（若满足浇水条件）

## 3. 页面布局与交互

### 3.1 表格结构

| 列名 | 说明 |
|------|------|
| 用户 | 显示/编辑文本 |
| 作物类型 | 显示 `16h作物` / `32h作物`，编辑时下拉选择 |
| 成熟倒计时 | 显示 `HH:MM:SS`，下方显示BOSS血条进度条（每10h一层，叠层展示，高层在上低层在下，层数随实际剩余时间动态变化，颜色逐层区分，第0层蓝色`#3b82f6`，第1层橙色`#f59e0b`，标签`xN`）。<br>**高亮规则**：剩余 ≤ 1h (`3600s`) 且 > 0 时行背景黄色预警，成熟后行背景绿色。<br>**成熟标签**：成熟后倒计时旁显示红色"熟"标签。<br>**排序**：点击列头循环切换（默认创建顺序 → 成熟倒计时升序 → 默认），列头旁有重置排序图标。 |
| 浇水湿润倒计时 | 上下结构：上方显示时间 `HH:MM:SS`，下方显示进度条（百分比着色：>50%绿色、20%-50%橙色、<20%红色）。水分干枯时显示"干枯"标签。 |
| 水分干枯时间 | 绝对时间 `MM-DD HH:mm`，动态刷新，跨日时显示"跨"标签 |
| 浇水减少时间 | 显示 `(最大湿润时间 - 当前湿润剩余) / 4`，格式 `Xh Xm` |
| 浇水成熟剩余时间 | 按第2节逻辑动态显示，每分钟刷新一次 |
| 操作 | 包含按钮：修改、浇水、一键播种、删除 |

### 3.2 按钮功能细节

#### 修改
- 点击后当前行进入编辑状态，冻结该行倒计时快照（记录点击时刻的 `matureCountdown` 和 `waterCountdown`）。
- 可编辑字段：用户（文本输入）、成熟倒计时（单个输入框，4位数字表示HHMM，如`0901`=9h1m）、浇水湿润倒计时（同格式）、作物类型（下拉）。
- 提交修改（回车或点击保存）：
    - 若用户未改动倒计时输入框，则使用**快照值减去编辑期间实际流逝时间**
    - 若用户改动了输入框，则直接采用用户输入值（秒数归零）
    - 作物类型改变时，成熟倒计时和湿润倒计时均重置为新类型的满值（忽略用户修改）

#### 浇水
- 可用条件：湿润剩余时间**严格小于**阈值且作物未成熟
- 不可用时按钮置灰，Tooltip说明原因
- 点击后：湿润倒计时重置为满值，成熟倒计时减少 `(最大湿润时间 - 剩余湿润时间) / 4`（结果≥0）
- 浇水后在成熟倒计时下方显示减少时间提示，3秒后渐隐消失

#### 一键播种
- 点击后操作列变为下拉选择（16h/32h）+ 确认按钮 + 取消按钮
- 选择类型后点击确认：重置为该类型满值，然后立即执行一次浇水效果
- 同类型作物播种**有效**（如32h→32h会重置为满值并浇水）
- 播种后显示撤销Toast，5秒内可撤销

#### 删除
- 点击弹出二次确认弹窗，确认后删除

#### 添加行
- 点击表格上方"添加行"按钮
- 新增一行：用户为空，类型默认16h，倒计时均为满值，`createOrder` 递增
- 新行自动进入编辑模式
- 多次添加时，仅最后一行为编辑状态

### 3.3 全局行为
- 倒计时每秒更新一次
- 数据持久化于 `localStorage`，刷新/关闭后恢复时自动计算流逝时间
- 多标签页冲突检测与提示
- 浇水成熟剩余时间列每分钟刷新一次

---

## 4. 数据持久化方案
- 存储键：`crop-management-data`
- 存储内容：JSON对象，含版本号、行数据数组及 `lastUpdateTime`
- 初始化时按流逝时间更新所有倒计时
- 增删改操作立即保存

---

## 5. 导入导出
- **导出**：将当前数据导出为JSON文件下载
- **导入**：选择JSON文件，覆盖当前数据，自动计算导入时间差并更新倒计时，做基本格式校验

---

## 6. UI/UX 要求
- 商业级CSS设计：阴影、圆角、合理间距、平滑过渡
- 成熟进度条：BOSS血条风格，叠层展示，颜色区分明显（蓝→橙→红→绿→紫）
- 进度条着色：>50%绿、20%-50%橙、<20%红
- 成熟标签：红色"熟"
- 行背景：<1h黄色预警，已成熟绿色
- 浇水减少提示：小字淡色，渐隐动画
- Tooltip、确认弹窗、Toast提示样式统一
- 移动端：表格横向滚动，操作区域增大

---

## 7. 技术约束
- 纯前端：HTML + CSS + JavaScript（原生实现）
- 无后端，无网络请求
- `setInterval` 更新倒计时，性能满足百行内需求
